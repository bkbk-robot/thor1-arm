# Contributing to Thor 1.0

Thanks for your interest! Thor 1.0 is a solo-built project, but contributions are welcome.

## Ways to Help

- **Report bugs** — Open an issue with steps to reproduce
- **Suggest features** — Ideas for new movements, voice commands, or hardware support
- **Improve docs** — Fix typos, add examples, clarify instructions
- **Share builds** — If you build your own Thor, let us know!

## How to Contribute

1. Fork the repo
2. Create a branch: `git checkout -b feature/your-idea`
3. Commit with clear messages (follow existing style)
4. Open a Pull Request

## Guidelines

- Keep code readable — this is a learning project for the community
- Test on real hardware if possible (ESP32-S3 + PCA9685 + MG996R)
- Don't break the existing `arm_ctrl.py` API without discussion

## Questions?

Open an issue or reach out to [@bkbk-robot](https://github.com/bkbk-robot).
